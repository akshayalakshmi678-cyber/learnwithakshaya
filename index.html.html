AI-Based Early Disease Risk Prediction System for Rural Areas

An AI-based application designed to predict early-stage disease risk using demographic and health survey data, supporting timely intervention in rural healthcare settings.

  • Performed data preprocessing and feature engineering.
  • Handled missing values and class imbalance.
  • Trained and evaluated Random Forest and Logistic Regression models.
  • Built a lightweight Flask interface for entering patient information and viewing risk predictions.

AI-Powered Study Assistant: Smart Notes Summarizer

An AI-powered study assistant that helps students understand lengthy lecture notes by summarizing PDF documents, extracting important concepts, and answering contextual questions.

  • Built PDF upload and text extraction.
  • Integrated BART and T5 transformer models for summarization.
  • Implemented a Retrieval-Augmented Generation system for contextual question answering.
  • Built a Flask interface for summaries and interactive questions.
